# ESTRATEGIA WEB JOSE MANGRIÑAN

OBJETIVO

Crear el archivo historico digital mas completo
sobre Jose Mangrinan.

PRINCIPIOS

1. Un documento solo se almacena una vez.

2. Un documento puede aparecer en muchos lugares.

3. Una fotografia puede estar relacionada con:
   - un año
   - un equipo
   - una persona
   - un acontecimiento
   - una anecdota

4. La cronologia sera el eje principal.

5. Los grandes acontecimientos tendran paginas propias.

6. Toda ficha historica debera incluir:
   - fecha
   - descripcion
   - documentos relacionados
   - fotografias relacionadas
   - personas relacionadas
   - acontecimientos relacionados

7. El usuario podra navegar por:

   - años
   - equipos
   - personas
   - acontecimientos
   - documentos
   - fotografías
   - anécdotas
