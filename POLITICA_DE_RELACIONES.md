# POLITICA DE RELACIONES
# ARCHIVO HISTORICO DIGITAL JOSE MANGRIÑAN

=================================================
OBJETIVO
=================================================

Definir como se relacionan entre si:

- años
- equipos
- personas
- acontecimientos
- documentos
- fotografias
- cromos
- hemeroteca
- anecdotas

para que un usuario pueda localizar la misma
informacion desde diferentes recorridos.

=================================================
PRINCIPIO GENERAL
=================================================

Todo elemento historico debe poder encontrarse
desde varios puntos de acceso.

No se duplicaran archivos.

Se crearan relaciones entre elementos.

=================================================

encontrarlo un investigador?

en la ficha correspondiente.
